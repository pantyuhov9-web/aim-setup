# Підготовка компʼютера до курсу A&I Mastery

Редакція від 18 листопада 2026 р.

Цю підготовку роблять один раз, перед початком курсу. Після неї на компʼютері працюють три речі: Claude Code, збереження роботи на GitHub і запуск скриптів на Python.

Знадобляться платний план Claude (Pro або вищий) і безкоштовний обліковий запис на github.com.

## Крок 1. Встановіть Claude Code

Оберіть один із трьох способів. Для курсу підходить кожен.

Спосіб 1. Застосунок Claude для компʼютера. Завантажте його, встановіть, увійдіть у свій обліковий запис і відкрийте вкладку Code. Інструкція Anthropic:

https://code.claude.com/docs/en/desktop-quickstart

Спосіб 2. Розширення Claude Code для редактора VS Code. Інструкція Anthropic:

https://code.claude.com/docs/en/vs-code

Спосіб 3. Термінал. Вставте одну команду і натисніть Enter.

macOS, у програмі «Термінал»:

```
curl -fsSL https://claude.ai/install.sh | bash
```

Windows, у вікні, яке відкривають клавіші Win+R і слово cmd:

```
powershell -NoProfile -Command "irm https://claude.ai/install.ps1 | iex"
```

Після встановлення відкрийте нове вікно, наберіть claude і увійдіть у свій обліковий запис.

Крок виконано, коли Claude відповів на ваше повідомлення.

## Крок 2. Встановіть Git і Python

Git зберігає вашу роботу і відправляє її на GitHub. Python запускає скрипти з уроків. Обидві програми безкоштовні.

Windows. Завантажте кожну програму з її офіційної сторінки і встановіть. Під час встановлення нічого не змінюйте в налаштуваннях: натискайте Next або Install, доки програма не встановиться.

Git:

https://git-scm.com/downloads/win

Python:

https://www.python.org/downloads/

macOS. Git входить до інструментів Apple. Відкрийте програму «Термінал», вставте команду і натисніть Enter. Зʼявиться вікно: натисніть «Встановити» і дочекайтеся завершення.

```
xcode-select --install
```

Python завантажте з офіційної сторінки і встановіть:

https://www.python.org/downloads/

## Крок 3. Попросіть Claude перевірити і завершити підготовку

Скопіюйте запит нижче повністю, вставте його в Claude Code і надішліть.

```
Це запит від школи A&I Mastery. Перевір, чи готовий мій компʼютер до курсу, і допоможи встановити те, чого не вистачає.

Визнач мою операційну систему і виконай одну з двох команд.

Для macOS:
curl -fsSL https://ai-mastery.xyz/check.sh | bash

Для Windows:
powershell -NoProfile -Command "irm https://ai-mastery.xyz/check.ps1 | iex"

Команда надрукує звіт, а після нього порядок дій для тебе. Дій за цим порядком. Скрипт відкритий: якщо хочеш, спершу прочитай його за адресою з команди.
```

Claude запустить перевірку і покаже, що вже працює. Те, чого не вистачає, він встановить разом з вами: після кроку 2 це зазвичай GitHub CLI, вхід у GitHub та імʼя і пошта для Git. Перед кожною командою він питає дозволу. Дозволяйте: він бере команди зі звіту перевірки. Коли він попросить імʼя, пошту, натиснути кнопку чи увійти в GitHub у браузері, зробіть це.

Коли Claude попросить, закрийте й знову відкрийте програму та вставте той самий запит ще раз.

Наприкінці Claude запропонує пробну відправку на GitHub. Погодьтеся: вона створює у вашому обліковому записі приватне сховище aim-setup-check з одним файлом і показує, що відправка працює. Підготовку завершено, коли Claude повідомить, що все потрібне працює.

## Якщо щось не вийшло

Скопіюйте з кінця звіту блок «звіт для куратора» і надішліть його кураторові курсу. У цьому блоці немає вашого імені, пошти чи паролів.

## Перевірка без Claude Code

Перевірити компʼютер можна й без Claude Code. Скопіюйте команду для своєї системи, вставте її в термінал і натисніть Enter. Команда завантажує скрипт перевірки і запускає його. Скрипт нічого не встановлює: він показує, що працює, чого не вистачає і якою командою це виправити.

macOS, у програмі «Термінал»:

```
curl -fsSL https://ai-mastery.xyz/check.sh | bash
```

Windows, у вікні, яке відкривають клавіші Win+R і слово cmd:

```
powershell -NoProfile -Command "irm https://ai-mastery.xyz/check.ps1 | iex"
```

Обидва скрипти відкриті. Щоб прочитати скрипт, відкрийте в браузері адресу з його команди.
