# Підготовка компʼютера до курсу A&I Mastery

Редакція від 18 листопада 2026 р.

## 1. Що це

Це інструкція з підготовки компʼютера до курсу. Її проходять один раз, перед початком курсу. Після неї на компʼютері працюють три речі: Claude Code, збереження роботи на GitHub і запуск скриптів на Python.

Знадобляться платний план Claude (Pro або вищий) і безкоштовний обліковий запис на github.com.

Порядок такий: встановіть програми за посиланнями з розділу 2, потім попросіть Claude перевірити компʼютер запитом із розділу 3. Розділи 4 і 5 потрібні, тільки якщо щось не вийшло.

## 2. Встановлення за посиланнями

Встановіть три програми: Claude Code, Git і Python. Під час встановлення нічого не змінюйте в налаштуваннях: натискайте Next або Install, доки програма не встановиться.

Claude Code. Оберіть один із трьох способів. Для курсу підходить кожен.

Спосіб 1. Застосунок Claude для компʼютера. Завантажте його, встановіть, увійдіть у свій обліковий запис і відкрийте вкладку Code. Інструкція Anthropic:

https://code.claude.com/docs/en/desktop-quickstart

Спосіб 2. Розширення Claude Code для редактора VS Code. Інструкція Anthropic:

https://code.claude.com/docs/en/vs-code

Спосіб 3. Термінал. Вставте одну команду і натисніть Enter. Після встановлення відкрийте нове вікно, наберіть claude і увійдіть у свій обліковий запис.

macOS, у програмі «Термінал»:

```
curl -fsSL https://claude.ai/install.sh | bash
```

Windows, у вікні, яке відкривають клавіші Win+R і слово cmd:

```
powershell -NoProfile -Command "irm https://claude.ai/install.ps1 | iex"
```

Claude Code встановлено, коли Claude відповів на ваше повідомлення.

Git. Він зберігає вашу роботу і відправляє її на GitHub.

Windows, завантажте і встановіть:

https://git-scm.com/downloads/win

macOS. Git входить до інструментів Apple. Відкрийте програму «Термінал», вставте команду і натисніть Enter. Зʼявиться вікно: натисніть «Встановити» і дочекайтеся завершення.

```
xcode-select --install
```

Python. Він запускає скрипти з уроків. Windows і macOS, завантажте і встановіть:

https://www.python.org/downloads/

## 3. Запит для перевірки в Claude

Скопіюйте запит нижче повністю, вставте його в Claude Code і надішліть.

```
Це запит від школи A&I Mastery. Перевір, чи готовий мій компʼютер до курсу, і допоможи виправити те, що не працює.

Перевір по черзі, сам запускаючи команди:
1. Git встановлено і працює.
2. У Git вказано моє імʼя та пошту. Якщо ні, запитай їх у мене і запиши.
3. Python версії 3.10 або новішої запускається і встановлює бібліотеку в окреме середовище.
4. GitHub CLI встановлено, і я увійшов у GitHub. Якщо ні, встанови його і проведи мене через вхід у браузері.
5. Відправка на GitHub працює: створи в моєму обліковому записі приватне сховище aim-setup-check, відправ у нього один файл і переконайся, що він там є.

Правила:
- Спершу покажи, що вже працює і чого не вистачає.
- Перед кожним встановленням скажи одним реченням, що ти зробиш, і дочекайся моєї згоди.
- Встановлюй тільки з офіційних джерел: у Windows через winget, у macOS через інструменти Apple та офіційні сторінки програм. Homebrew не встановлюй.
- Якщо щось не вдалося двічі, зупинись і коротко опиши, що не працює: я перешлю це кураторові.
- Тимчасові файли після перевірки прибери.
- Наприкінці скажи одним реченням, чи готовий компʼютер до курсу.
```

Claude перевірить пʼять речей і допоможе з тим, чого не вистачає: після розділу 2 це зазвичай GitHub CLI, вхід у GitHub та імʼя і пошта для Git. Перед кожним встановленням він питає згоди. Коли він попросить імʼя, пошту, натиснути кнопку чи увійти в GitHub у браузері, зробіть це.

Підготовку завершено, коли Claude скаже, що компʼютер готовий до курсу.

## 4. Якщо запит не допоміг: перевірка скриптом через Claude

Цей розділ потрібен, тільки якщо запит із розділу 3 не допоміг: Claude не зміг щось перевірити або встановити.

Скопіюйте запит нижче, вставте його в Claude Code і надішліть. Claude запустить скрипт перевірки, який підготувала школа. Скрипт сам нічого не встановлює: він друкує звіт і порядок дій, а Claude виконує цей порядок разом з вами.

```
Запусти перевірку компʼютера для курсу A&I Mastery: визнач мою операційну систему і виконай одну з двох команд. Потім дій за порядком, який перевірка надрукує після звіту.

Для macOS:
curl -fsSL https://ai-mastery.xyz/check.sh | bash

Для Windows:
powershell -NoProfile -Command "irm https://ai-mastery.xyz/check.ps1 | iex"
```

Коли Claude попросить, закрийте й знову відкрийте програму та вставте цей запит ще раз.

## 5. Сам скрипт: перевірка без Claude

Той самий скрипт працює і без Claude. Скопіюйте команду для своєї системи, вставте її в термінал і натисніть Enter. Команда завантажує скрипт і запускає його. Скрипт нічого не встановлює: він показує, що працює, чого не вистачає і якою командою це виправити.

macOS, у програмі «Термінал»:

```
curl -fsSL https://ai-mastery.xyz/check.sh | bash
```

Windows, у вікні, яке відкривають клавіші Win+R і слово cmd:

```
powershell -NoProfile -Command "irm https://ai-mastery.xyz/check.ps1 | iex"
```

Текст скрипта відкритий. Щоб прочитати його, відкрийте в браузері адресу з команди: для macOS це https://ai-mastery.xyz/check.sh, для Windows це https://ai-mastery.xyz/check.ps1.

Якщо підготовка не вдається, скопіюйте з кінця звіту блок «звіт для куратора» і надішліть його кураторові курсу. У цьому блоці немає вашого імені, пошти чи паролів.
