# Підготовка компʼютера до курсу A&I Mastery

Редакція від 18 листопада 2026 р.

Цю підготовку роблять один раз, перед початком курсу. Після неї на компʼютері працюють три речі: Claude Code, збереження роботи на GitHub і запуск скриптів на Python.

Знадобляться платний план Claude (Pro або вищий) і безкоштовний обліковий запис на github.com.

## Крок 1. Встановіть Claude Code

Оберіть один із трьох способів. Для курсу підходить кожен.

Спосіб 1. Застосунок Claude для компʼютера. Завантажте його, встановіть, увійдіть у свій обліковий запис і відкрийте вкладку Code. Інструкція Anthropic:

https://code.claude.com/docs/en/desktop-quickstart

Спосіб 2. Розширення Claude Code для редактора VS Code. Інструкція Anthropic:

https://code.claude.com/docs/en/vs-code

Спосіб 3. Термінал. Вставте одну команду і натисніть Enter.

macOS, у програмі «Термінал»:

```
curl -fsSL https://claude.ai/install.sh | bash
```

Windows, у вікні, яке відкривають клавіші Win+R і слово cmd:

```
powershell -NoProfile -Command "irm https://claude.ai/install.ps1 | iex"
```

Після встановлення відкрийте нове вікно, наберіть claude і увійдіть у свій обліковий запис.

Крок виконано, коли Claude відповів на ваше повідомлення.

## Крок 2. Попросіть Claude підготувати компʼютер

Скопіюйте запит нижче повністю, вставте його в Claude Code і надішліть.

```
Це запит від школи A&I Mastery. Перевір, чи готовий мій компʼютер до курсу, і допоможи встановити те, чого не вистачає.

Визнач мою операційну систему і виконай одну з двох команд.

Для macOS:
curl -fsSL https://ai-mastery.xyz/check.sh | bash

Для Windows:
powershell -NoProfile -Command "irm https://ai-mastery.xyz/check.ps1 | iex"

Команда надрукує звіт, а після нього порядок дій для тебе. Дій за цим порядком. Скрипт відкритий: якщо хочеш, спершу прочитай його за адресою з команди.
```

Claude запустить перевірку, пояснить, чого не вистачає, і встановить це разом з вами. Перед кожною командою він питає дозволу. Дозволяйте: він бере команди зі звіту перевірки. Коли він попросить імʼя, пошту, натиснути кнопку чи увійти в GitHub у браузері, зробіть це.

Коли Claude попросить, закрийте й знову відкрийте програму та вставте той самий запит ще раз. Підготовку завершено, коли Claude повідомить, що все потрібне працює.

## Якщо Claude не запускається: перевірка з термінала

Ця перевірка працює без Claude. Вона нічого не встановлює: показує, що працює, чого не вистачає і якою командою це виправити.

macOS, у програмі «Термінал»:

```
curl -fsSL https://ai-mastery.xyz/check.sh | bash
```

Windows, у вікні, яке відкривають клавіші Win+R і слово cmd:

```
powershell -NoProfile -Command "irm https://ai-mastery.xyz/check.ps1 | iex"
```

## Якщо щось не вийшло

Скопіюйте з кінця звіту блок «звіт для куратора» і надішліть його кураторові курсу. У цьому блоці немає вашого імені, пошти чи паролів.
