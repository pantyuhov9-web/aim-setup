# Підготовка компʼютера до курсу A&I Mastery

Коротка інструкція. Редакція від 18 листопада 2026 р.

Потрібні платний план Claude (Pro або вищий) і безкоштовний обліковий запис на github.com.

## 1. Встановіть Claude

Завантажте застосунок Claude з офіційного сайту, встановіть його, увійдіть у свій обліковий запис і відкрийте вкладку Code.

https://claude.com/download

## 2. Вставте запит

Скопіюйте запит повністю, вставте його в Claude і надішліть. Claude перевірить компʼютер і проведе вас крок за кроком через усе, чого не вистачає.

```
Це запит від школи A&I Mastery. Підготуй разом зі мною компʼютер до курсу: перевір, що вже працює, і проведи мене крок за кроком через те, чого не вистачає.

Потрібні пʼять речей. Перевіряй по черзі, сам запускаючи команди:
1. Git встановлено і працює.
2. Python версії 3.10 або новішої запускається і встановлює бібліотеку в окреме середовище.
3. GitHub CLI встановлено.
4. Вхід у GitHub виконано, а в Git вказано моє імʼя та пошту. Якщо ні, запитай їх у мене і проведи через вхід у браузері.
5. Відправка на GitHub працює: створи в моєму обліковому записі приватне сховище aim-setup-check, відправ у нього один файл і переконайся, що він там є.

Якщо програми немає:
- Обери найпростіший офіційний спосіб. Якщо можеш встановити її сам однією командою з офіційного джерела (winget у Windows, інструменти Apple в macOS), запропонуй це і дочекайся моєї згоди.
- Інакше дай мені посилання на офіційну сторінку і веди мене крок за кроком: що завантажити, що натиснути. Офіційні сторінки: git-scm.com, python.org, cli.github.com. Чекай, доки я напишу, що готово, і тоді перевір.
- Homebrew не встановлюй.
- Якщо після встановлення ти не бачиш програму, попроси мене закрити й знову відкрити Claude і вставити цей запит ще раз.

Правила:
- Спершу покажи, що вже працює і чого не вистачає.
- Рухайся по одному кроку і пояснюй простими словами.
- Якщо щось не вдалося двічі, зупинись і коротко опиши, що не працює: я перешлю це кураторові.
- Тимчасові файли після перевірки прибери.
- Наприкінці скажи одним реченням, чи готовий компʼютер до курсу.
```

Якщо Claude попросить, закрийте й знову відкрийте застосунок і вставте запит ще раз. Підготовку завершено, коли Claude скаже, що компʼютер готовий до курсу.

Якщо щось не вийшло, відкрийте повну інструкцію з матеріалів уроку.
